# Security

## Report a vulnerability

Email [support@taskheroics.com](mailto:support@taskheroics.com) with the subject
`TaskHero for Anki security report`. Please don't report vulnerabilities in a
public issue.

Include the add-on version, Anki version, operating system, steps to reproduce
the problem, and its potential impact. Remove tokens and personal study data
from any logs or screenshots.

We'll investigate and coordinate a fix and disclosure when appropriate.

## If your token is exposed

Treat your Anki integration token like a password. If you've shared it
accidentally, revoke or replace it in TaskHero's **Integrations & API → Anki**
card. Then **Disconnect** in the add-on settings and reconnect with a new token.

Disconnect alone removes the token from that Anki profile; it doesn't revoke
the token in TaskHero.
